# NBA Fantasy Waiver Wire Automation

This project automates the process of tracking **NBA Fantasy Waiver Wire** data and **last 3-game player stats**, then uploads the data to **Google Sheets**.

## Features
- Scrapes **FantasySP** for the **25 most added NBA players**.
- Retrieves **last 3-game averages** for these players from **NBA.com API**.
- Uses **Google Sheets API** to upload & update data in an existing spreadsheet.
- Implements **fuzzy string matching** to improve player name recognition.
- Uses **Selenium WebDriver** for reliable scraping.
